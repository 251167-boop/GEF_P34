Automatic page scan

Page checks start when a website loads. You can request another scan here.

What the scan checks

  • WebShield checks ordinary web pages automatically as they load. Chrome grants it access to read the pages you visit so it can do this.
  • Page and form signals are analyzed locally. Form values and passwords are never read by the site-risk scan.
  • The reputation check sends a sanitized URL to the local scanner, which forwards it to Google Safe Browsing when configured.
  • Query strings, fragments, and long token-like path segments are removed before lookup.

Green means no strong warning was found; it does not prove a site is safe. Scanning does not block navigation.
